# Mresource

> 这个仓库收录我的所有的曾用或现用的原创素材

个人原创资源库，集中存放图标与图片素材，以便随时引用。

- 该库使用 **CC BY-SA 4.0** 许可证

---

为了规避潜在的侵权问题，我去除了我的项目库里的所有旧资源并替换成自制自绘的资源文件，创建这个库的目的是方便声明我的资源文件所使用的许可证，以及方便存储和取用资源。

由于目前我工作是比较忙的，并且这个决定过于仓促，包括替换旧项目资源文件也是刚刚没多久的事儿，故只得暂且用手绘草图 + AI 加工的图像素材了，当然原稿都是手绘的，只是画的很烂，只好用 AI 给改成我想要的样子了。
